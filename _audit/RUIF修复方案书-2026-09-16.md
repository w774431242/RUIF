## 1. 主理人裁定（跨部门冲突与错误更正）

### R-1 · 更正：`GUI.matrix` 与 `GUIClip` 是同一状态
反编译证据：`GUI.matrix` get/set 即为 `GUIClip.GetMatrix()/SetMatrix(value)`（`UnityEngine.GUI.cs:300-309`）；`BeginGroup`→`GUIClip.Push`（`:2014`）、`BeginScrollView`→`GUIClip.Push`（`:2161`）。

**裁定**：
1. 撤回审计阶段"两条变换路径独立、混用必错位"的表述。
2. `Widgets.DrawLine` 在滚动视图内**是否错位未获证实**，且存在原版反证据（`Verse.ReorderableWidget.DrawLine` 在调用方裁剪上下文内使用之）。
3. **`Widgets.DrawLine` 8 处改为"先实机 A/B 再定"**（30 分钟：`BeginScrollView` 内并列画 `Widgets.DrawLine` 与烘焙折线，滚动到非零偏移截图）。**不按原计划直接统一烘焙**——需先评估烘焙引入的新风险（半透明接缝叠加、`TexCache` 128 条容量挤压）。
4. 两处零风险改动**立即执行**：`DomainCandAtoms.cs:126` 的纯水平箭头改 `Draw.LineH`（零矩阵）；`NavAtomsB.cs:60` 删除包住显式传色调用的死 `using (Draw.Color(c))`。

### R-2 · 裁定：`Tr.cs` 三参重载 **保留**
- 表现部 B1 修复中 `PawnTableAtoms` 状态行需 `string + int + int` 三参（`Tr.Get(key, NamedArgument×3)`）；机制部则判其为死代码、建议删除（依据：`internal` 类型不受 `[Obsolete]` 约束、编译期双向零命中）。
- **两方判断均正确，冲突在时序**：机制部的"死代码"基于**当前**状态；表现部的需求是**即将产生**的调用点。
- **裁定：保留**。理由：删除的唯一收益是清理，而保留可避免 B1 为绕开 3 参上限而拆成两键（表现部已给出拆键备选，但那会使同一句文案跨两个键、增加维护面）。B1 落地后该重载即为活代码。
- 连带：该重载的**陈旧注释**（`Tr.cs:60-62` 指向已删除的设置页）**仍须删除**——它描述了不存在的事物，与 EXC-003 同源。注释删、方法留。

### R-3 · 裁定：B3 的修法形态
采纳机制部方案，并明确其量级：

```csharp
// 修法（Source/Core/Measure.cs）
public static float RowHeight(GameFont font)
    => Text.LineHeightOf(DegradeTiny(font, Text.TinyFontSupported));

/// 镜像原版 Verse.Text.Font setter 的静默降级规则。纯函数 ⇒ 可离线单测。
internal static GameFont DegradeTiny(GameFont font, bool tinySupported)
    => (font == GameFont.Tiny && !tinySupported) ? GameFont.Small : font;
```

**不得改为 `static readonly` 缓存**：`Text.TinyFontSupported` 运行期可变（玩家随时勾选），任何"首次访问即定值"的缓存都会冻错值。

**量级说明（务必写进排期）**：这不是改一个常量，而是**补上一条从未接线的推导**——
- 框架**从未调用** `Measure.RowHeight`（全仓零调用）；
- 真正失准的是 **42 处写死的矩形高度**（18 处 `Rect.h=` + 24 处 `Take(n<22)`），涉 43 个 `FontLabel` 引用点、18 个文件；
- 其中 **10 处几何耦合（文字压图形）为必修**，32 处（行间重叠/裁字）建议修。

**为何 14px 一定压弧（机制解释，用于说服后来者）**：`Draw.Label` → `Widgets.Label` → `GUI.Label`，而 **`GUI.Label` 不裁切**；`CurFontStyle` 只设 alignment/wordWrap。单行文本按**真实行高从 rect 顶端外溢** ⇒ rect 高度对 `UpperLeft` 不参与裁切 ⇒ 14px 容器装 22px 文字，文字底边 `r.y+22` 对弧顶 `r.y+15`，**压弧 7px**。

### R-4 · 更正：账户口径的三处高估
| 项 | 更正后 |
|---|---|
| `Array.ConvertAll(pts, λ)` | **lambda 本身不分配**（非捕获 lambda 由编译器缓存在静态字段）；分配的是每次 `new` 出的 `float[]`（4 个/帧） |
| 数值→文本分配点 | 审计列 3 处，实为 **43 处**（全仓枚举，剔 `*Fmt.cs` 纯计算层） |
| `new Vector2/new Rect` | **值类型构造，零堆分配，不计违规** |
