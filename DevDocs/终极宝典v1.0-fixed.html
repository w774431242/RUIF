基础渲染层

UnityEngine IMGUI · GUI.color / Rect
框架地基：设计令牌与绘制原子。对应 RUIF 的 Theme / Draw / Layout 三层，全部走官方公开 IMGUI。

设计令牌扩展（新增语义令牌）

在 v0.3 Vanilla/Dark 双主题基础上，为图鉴组件新增的组件级语义令牌——全部由调色板派生，第三方主题注册时一次赋值。

装饰层与热门风格主题（⛔ 已于 v1.0.0 移除 · 历史章节）

主题 = 16 色调色板（Palette）+ 装饰配方（ThemeDecor，6 维度）。装饰全部由矩形与线段程序化绘制——零贴图、零 shader、零资产依赖。用法一句 DrawDecor.Panel(rect)：面板/卡片立即获得当前主题的完整观感。

维度可选档实现要点
SurfaceStyle 底色纯色 / 上亮渐层 / 下亮渐层强调色按 18% 混入后纵向插值；行数 ≤48 自适应
EdgeStyle 边框无 / 极细 / 单线 / 双线 / 虚线 / 霓虹发光霓虹 = 多层半透明外扩 + 主描边
CornerStyle 角形直角 / 切角 / 圆角 / 裁角逐行矩形近似（无 9-slice），≤56 行
OverlayStyle 纹样无 / 扫描线 / 黄黑斜纹 / 网格 / 点阵斜纹走 45° 旋转坐标系；各档独立硬上限
MotionStyle 动效无 / 呼吸 / 流光 / 掠光 / 闪烁相位由时间参数传入，组件零状态；传 0 即冻结
TickStyle 角标无 / 四角标记 / 左右导轨 / 方括号HUD 取景框感
性能纪律：纹样有硬上限（扫描线 ≤64 / 网格 ≤44 轴 / 点阵 ≤220 / 斜纹 ≤40），渐层与形状按高度自适应（≤48 / ≤56 行）——面板再大也不会画出上千条线；绘制路径零堆分配。
颜色纪律（白名单⑤ · 历史）：装饰层的渐变 / 发光 / 纹样不产生新色值——全部由既有令牌经 Color.Lerp 或 Draw.WithAlpha 派生。（旧装饰层 DrawDecor 已随换肤层移除，本段为历史设计纪律。）
