## 批次 B-R11（格 41-44 = W A A W）· BenchNavLayout 段高重算
- `VStack.Take` 反编译语义：**每项后推进 `height + gap`**（n 项需求 = ΣH + (n−1)×gap），超出自动裁剪不越界——但裁剪 = 末位组件被压扁，若组件内部不自适应即画出矩形外。段高算术必须把 CapH 标签行也计为项（label+组件交替 → 项数是组件数的 2 倍）。
- BenchNavLayout 三段各溢 62/50/62（400/390/384 → 462/440/446）：B-R3 签名审计「零实缺」≠ 几何无缺陷，段高重算对每面都要独立做。
- 「吃 Rest 的组件」天然安全（留白不算越界），算术检查可跳过；Take 链末位组件是裁剪重灾区。
