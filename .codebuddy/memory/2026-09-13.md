### ⛔ 本轮踩过并已修的三类真实缺陷

1. **构造函数 vs 对象初始化器时序**（实机 Bug「tab 能点但无分类」）：`new T { Prop = v }` 是**先构造函数、后赋 Prop**。
   `BenchAtoms42` 构造函数里跑 `Build()`（内含按 `OnlyTab` 筛选），赋值时 `OnlyTab` 仍为 null ⇒ **8 个实例全装了全部族**。
   **修法：改成属性，setter 里 `families.Clear(); cards.Clear(); Build();` 重建。**
   **通用规则：凡「配置项影响构造期行为」的一律用属性，不用公开字段。**
2. **编号跨类撞号**：族代号 `INP` 横跨 4 个类，而序号按**类**编 ⇒ `SearchField` 与 `BatchSliders` 都拿到 `INP-02`。
   **修法：序号按族代号连续。通用规则：前缀作用域必须与序号作用域一致。**
3. **编号排序缺类优先级**（用户实机抓出「73/74 编号错误」）：主体类 `Charts` 被 `ChartCandAtoms`/`ChartCandFmt` 挤到 `CHT-19` 起。
   **修法：族内排序键加「主体类(0) → *Cand 候选(1) → *Fmt 工具(2)」** ⇒ `Charts` = `CHT-01…10`。
   **通用规则：编号排序必须让主体优先于候选/工具。**
4. **死状态**：`poHeld` 恒定 false ⇒ 编译器报 **`CS0649`**。**修法不是删，而是让状态真的可达**（运行中点=暂停，跑满后点=重开）。

## 【宝典按分类拆分】→ `docs/02-组件图鉴/分类图鉴/`（8 文件）
用户要求把《终极宝典》按组件类型拆成独立图鉴 HTML。
- **关键坑**：原宝典是单文件，文末一整段 `<script>` 内**图表 IIFE** 与**工业 IIFE** 直接对 `#c-th-*`/`#n-th-*` 等专属元素 `.onclick`/`.addEventListener`；若某分类文件不含该域，`querySelector` 返回 null → 抛错 → 阻断后续全局接线（主题切换/搜索/导航全失效）。
- **方案（无损、可复现）**：保留原 `<style>` 与整段脚本**不变**；每个分类文件只放该域 `<section>`，并对"缺失域"的脚本必需元素注入**隐藏空桩 `<div id="_stubs" style="display:none">`**，使脚本任何分类页都不抛错。
  - 桩集合（已枚举全部 `getElementById`/`querySelector('#…')` 确认覆盖）：`c-chips,c-th-dark,c-th-vanilla,c-tiers,c-summary`（图表）、`n-th-dark,n-th-vanilla`（工业）、`auditCounts`（基础）、`navAll`(脚本内 `if(!b)return` 已守卫)。
- **生成器**：`_scripts/split_treasure.ps1`（改宝典后重跑即刷新 8 文件）。分类映射：原子=d-base / 输入=d-input / 数据=d-data / 反馈=d-alert / 导航=d-nav+d-nav-x / 工业=d-industry / 图表=d-chart / 候选=d-eng。
- **产物**：8 个 `XX组件图鉴.html`（130–180KB，含共享样式+脚本+本域内容+跨分类侧栏链接），已写进 `docs/00-文档导航.md`。
- **验证**：静态枚举确认脚本所有 ID 引用均有真实元素或 stub 兜底；`applyFilter` 仅由图表筛选按钮触发（非图表页无该按钮故不触发，且 `buildTiers` 已动态创建 `#c-tier0..3`）。未跑浏览器实测（环境无）。
