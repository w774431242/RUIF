## 使用约定

- 找组件看 `标准规范组件预览.html`；查真实 API 签名看 `API参考.md`；新手从 `零基础上手教程.html` 起步。
- 改了代码后，`API参考.md` 需用 `gen_api_reference.ps1` 重新生成以保持同步。
