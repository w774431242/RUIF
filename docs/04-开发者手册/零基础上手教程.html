一句话定位：RUIF 是“画 UI 的零件箱”——它给你按钮条、状态点、图表、表格、选项卡、对话框等零件， 以及一套固定的颜色/间距/字号令牌；它不给你现成界面，你的界面由你自己用这些零件拼出来。

① 三个概念（30 秒）

概念 1 · RUIF 是“框架 Mod”，你只引用、不内嵌

和 Harmony / HugsLib 一个模式：玩家订阅 RUIF 这个 Mod，游戏启动时全游戏只加载一份 RUIF.dll。 你的 Mod 只在编译期引用它（Private=false），绝不把 dll 复制进自己包里——否则会出现"两份不同版本 dll"的经典冲突。

概念 2 · 组件 = 静态方法 + 一个矩形（Rect）

RUIF 里没有“控件对象”，没有属性页，也不需要 new。你要画什么，就调一个静态方法，告诉它画在哪块矩形里：

RUIF.Draw.Label(rect, "人口 7", RUIF.Tokens.FontBody, RUIF.Tokens.Text, TextAnchor.MiddleLeft);
//  ↑ 画在哪      ↑ 画什么   ↑ 字号令牌         ↑ 颜色令牌       ↑ 对齐

所以每个组件都长得一样：类型.方法(rect, 数据…)。会画一个，就会画一百个。

概念 3 · 布局 = 一个“游标”，一路切过去

你不需要算坐标。要一列三行，就拿一根纵向游标，从上往下切三刀：

var col = RUIF.Layout.Column(inRect, RUIF.Tokens.Gap);   // 竖着切
Rect head = col.Take(30f);    // 第 1 行：高 30
Rect body = col.Take(120f);   // 第 2 行：高 120
Rect foot = col.Rest;         // 剩下的全给它

口诀：先拿游标 → 再切格子 → 最后往格子里画。横着切就换 Layout.Row（切宽度）。

诚实提醒：RUIF 是即时模式（每帧重画一次，和原版 IMGUI 一致）。你要写一个 Window 子类、 实现 DoWindowContents(Rect)——这部分是原版知识，本教程会给你完整模板，照抄即可。想深入看原版机制，见 《接入指南与引擎可行性审计.html》。

② 五分钟接上（两种模式，选一个）

模式 A · 硬依赖（推荐：99% 的场合都用这个）

适用：你的 Mod 必须有 RUIF 才能用（没装就没意义）。

  1. csproj 里加引用（路径按你的工程改）：<Private>false</Private> 是重点——不要把 dll 复制进你的包。
  2. About.xml 声明依赖，让游戏保证加载顺序。
  3. 代码里做版本门控（可选但推荐）：Api.IsAvailable("1.0") 确认框架在位。
<!-- 第 1 步：你的 Mod .csproj -->
<ItemGroup>
  <Reference Include="RUIF">
    <HintPath>$(RimWorldPath)\Mods\RUIF\Assemblies\RUIF.dll</HintPath>
    <Private>false</Private>   <!-- 关键：不要随包分发 -->
  </Reference>
</ItemGroup>
<!-- 第 2 步：你的 About.xml -->
<modDependencies>
  <li>
    <packageId>PersonalChronicle.RUIFramework</packageId>
    <displayName>RUI Framework (RUIF)</displayName>
  </li>
</modDependencies>
<loadAfter><li>PersonalChronicle.RUIFramework</li></loadAfter>
// 第 3 步：版本门控（放在你窗口的构造器或 Mod 构造器里）
using RUIF;
if (!Api.IsAvailable("1.0")) { /* 框架太旧／缺失 → 给出提示并禁用入口 */ }

模式 B · 软依赖（可选：想让玩家不装 RUIF 也能用你的 Mod）

关键点只有一个：“探测”和“调用”要分开。探测用反射扫类型名（不引用 RUIF 类型，框架缺失也不会炸）； 真正调用 RUIF 的代码全部关进独立方法里。

internal static class RuifProbe
{
    private static bool? cached;
    internal static bool Available
    {
        get
        {
            if (!cached.HasValue) cached = FindApiType() != null;
            return cached.Value;
        }
    }
    // 只扫类型名字符串，不引用 RUIF 类型 —— 框架没装也不会抛
    private static Type FindApiType()
    {
        foreach (System.Reflection.Assembly asm in AppDomain.CurrentDomain.GetAssemblies())
        {
            Type t = asm.GetType("RUIF.Api", false);
            if (t != null) return t;
        }
        return null;
    }
}

internal static class RuifBridge
{
    // 所有会触发 RUIF 类型加载的调用都关在这里
    [MethodImpl(MethodImplOptions.NoInlining)]
    internal static bool HasApi(string minVersion)
    {
        return Api.IsAvailable(minVersion);
    }
}
为什么必须这样写？RUIF 类型在框架缺失时，任何引用它的代码路径会在 JIT 期抛 FileNotFoundException／TypeLoadException——不会走到你精心准备的 else 分支。 这是 C# 的运行期行为，不是 RUIF 的脾气。

③ 画第一个窗口（完整代码，可直接跑）

把下面整段贴进你的工程，就是一个能开的窗口。逐行注释在右边。

using RUIF;
using UnityEngine;
using Verse;

public class Dialog_MyFirstWindow : Window
{
    public override Vector2 InitialSize => new Vector2(560f, 320f);   // 窗口初始大小

    public override void DoWindowContents(Rect inRect)
    {
        // 1) 竖着切三行：标题 / 内容 / 按钮
        var col = Layout.Column(inRect, Tokens.Gap);
        Rect head = col.Take(30f);
        Rect body = col.Take(200f);
        Rect foot = col.Rest;

        // 2) 标题
        Draw.Label(head, "我的第一个 RUIF 窗口", Tokens.FontValue, Tokens.Text, TextAnchor.MiddleLeft);

        // 3) 内容：一块面板 + 两行统计
        Draw.Box(body, Tokens.Panel);
        Draw.Border(body, Tokens.Border);
        Rect inner = Layout.Inset(body, Tokens.CardPadX, Tokens.CardPadY);
        var rows = Layout.Column(inner, Tokens.SpaceXs);
        PanelAtoms.SectionBar(rows.Take(Tokens.SectionTitleHeight), "殖民地概览", "2 项", true);
        PanelAtoms.StatRow(rows.Take(22f), "人口", "7", 7f / 12f, Tokens.Accent);
        PanelAtoms.StatRow(rows.Take(22f), "食物", "1 240");

        // 4) 按钮：RUIF 不提供通用按钮，直接用原版 Widgets
        if (Widgets.ButtonText(foot, "确定")) Close();
    }
}
打开它：Find.WindowStack.Add(new Dialog_MyFirstWindow());（放在某个按钮/Def 的入口里即可）。

想让它变成 Mod 设置页或 Tab？

RUIF 不挑容器，上面的 DoWindowContents 代码同样适用于 ITab、MainTabWindow、 Dialog。你只要把 inRect 交给 Layout.Column，剩下的都一样。

⑥ 六个必踩的坑（含正解）

坑 1 · 类里自己有个 Draw 方法 → CS0119

如果你写的类里已经有 void Draw(...)，那裸写 Draw.Label(...) 会被编译器解析成 “你自己那个方法组”，于是报 CS0119。

public void Draw(Rect r)
{
    // ❌ Draw.Label(r, ...);              ← CS0119
    RUIF.Draw.Label(r, "全限定调用", Tokens.FontBody, Tokens.Text, TextAnchor.MiddleLeft);   // ✅
    RUIF.Draw.Box(r, Tokens.Panel);                                                            // ✅
}

坑 2 · 手改 GUI.color → 染色泄漏到全游戏

原版 Widgets.DrawBoxSolid 会重置 GUI.color，手写 try/finally 又容易漏。用作用域， 离开 using 自动恢复：

using (RUIF.Draw.Color(Tokens.AccentSoft)) RUIF.Draw.Box(r, Tokens.AccentSoft);
using (RUIF.Draw.Font(Tokens.FontValue))    RUIF.Draw.Label(r, "大号", Tokens.FontValue, Tokens.Text, TextAnchor.MiddleCenter);
using (RUIF.Draw.Anchor(TextAnchor.UpperRight)) RUIF.Draw.Label(r, "右上", Tokens.FontLabel, Tokens.Muted, TextAnchor.UpperRight);
using (RUIF.Draw.Enabled(false)) Widgets.ButtonText(r, "禁用态按钮");   // 想半透明/不可点：用 Enabled
Color 半透明 = RUIF.Draw.WithAlpha(Tokens.Panel, 0.5f);                          // 而不是自己 new Color

坑 3 · 到处找“RUIF 的按钮” → 找不到

RUIF 故意不提供通用按钮（按钮是最容易做歪的控件）。请直接用原版：

if (Widgets.ButtonText(r, "确定")) { /* 被点击 */ }
// 要禁用：原版 ButtonText 没有 disabled 参数 —— 用 Draw.Enabled(false) 包住，或用 active:false 重载

坑 4 · Command 二义性 → CS0104

RUIF.Command（给命令面板用）与 Verse.Command（原版存在）同名。 同时 using RUIF; using Verse; 时必须写全：

var cmds = new List<RUIF.Command>();          // ✅ 写 RUIF.Command
// var cmds = new List<Command>();            ← ❌ CS0104：Command 是 RUIF.Command 和 Verse.Command 之间的不明确引用

坑 5 · 照抄签名却报 CS1503“无法从 float[] 转换为 float[*,*]”

个别组件收的是多维数组。例如热力网格是 grid[行, 列]：

Charts.HeatmapGrid(r, new[,] { { 0.1f, 0.4f, 0.9f }, { 0.3f, 0.6f, 0.2f } });   // ✅ 2 行 3 列

（API参考.md 曾把 float[,] 误印成 float[]，v1.0.1 已修正——若你手上是旧版文档，以签名报错提示的 [*,*] 为准。）

坑 6 · 自己 new Color(...) 调色

RUIF 的颜色是固定令牌（Tokens.*），不是可换肤主题。想做自定义配色，就在你自己的 Mod 里持有颜色常量； 想基于令牌派生（变暗/半透明），用 Draw.WithAlpha。

别期待的东西（说清楚，免得你白找）：框架没有主题/换肤、没有保留模式自动 diff、 没有内置演示界面、没有圆角/自适应高度的 Layout 容器。这些都在《接入指南》里按 ✅/⚠️/❌ 三级如实标注。

⑦ 本地化（你的文案要能翻译）

  • RUIF 自己带 Languages/ChineseSimplified|English 各 60 键（组件内部文案），你不用管。
  • 你传给 RUIF 的字符串由你负责：写死中文 = 英文玩家看到中文。正确做法是走原版翻译： "MyMod_Label".Translate()，键写进你自己的 Languages/*/Keyed/*.xml。
  • Def 里的文本走 DefInjected，代码里的文本走 Keyed——这是原版纪律，RUIF 不改变它。
  • 不要拿翻译结果做逻辑判断（中英文案都可能被玩家改）。

⑧ 报错对照表（看到报错先查这里）

报错真实原因怎么改
CS0119：「Draw」是方法组而非类型你类里定义了名为 Draw 的方法写全限定 RUIF.Draw.*
CS0104：Command 是不明确的引用RUIF.Command 与 Verse.Command 同名写全限定 RUIF.Command
CS1503：无法从 float[] 转换为 float[*,*]该组件要的是二维数组用 new[,] { { … }, { … } }
CS0618：Translate 已过时用了 params object[] 重载改用 Translate(NamedArgument)
CS0117：类型不包含某成员看了过期文档或猜的 API 名以随包 DevDocs/API参考.md 为准（它是从 dll 反射生成的）
运行期 FileNotFoundException: RUIF玩家没装 RUIF，或你走软依赖却直接调了 RUIF 类型硬依赖：About.xml 写 modDependencies；软依赖：把调用隔离进独立方法
界面颜色全乱 / 文字串色手改了 GUI.color 没恢复一律用 Draw.Color / Draw.WithAlpha / Draw.Enabled 作用域
你的包里有 RUIF.dllPrivate 没设 false改成 <Private>false</Private>，并删掉包内那份副本

⑩ 完整示例：一个“殖民地状态”窗口（约 120 行）

把本教程的零件拼起来的样子 —— 有滚动、选项卡、统计行、输入控件、图表、反馈。整段已真编译验证。

using RUIF;
using UnityEngine;
using Verse;

public class Dialog_ColonyPanel : Window
{
    private readonly float[] series = { 3f, 6f, 2f, 9f, 4f, 7f };
    private readonly float[] shares = { 0.4f, 0.2f, 0.2f, 0.2f };
    private Vector2 scroll;
    private int tab;
    private float tabX;
    private int segIndex;
    private float amount = 0.5f;

    public override Vector2 InitialSize => new Vector2(780f, 560f);

    public override void DoWindowContents(Rect inRect)
    {
        var col = Layout.Column(inRect, Tokens.Gap);
        Rect head = col.Take(30f);
        Draw.Label(head, "殖民地状态", Tokens.FontValue, Tokens.Text, TextAnchor.MiddleLeft);

        // 可滚动内容区
        Rect view = Layout.BeginScroll(col.Take(400f), 640f, ref scroll);
        var v = Layout.Column(view, Tokens.BlockGap);

        // 顶部选项卡
        NavAtoms.TabBar(v.Take(30f), new[] { "总览", "库存", "人员" }, ref tab, ref tabX);

        // 统计面板
        Rect card = v.Take(120f);
        Draw.Box(card, Tokens.Panel);
        Draw.Border(card, Tokens.Border);
        var c = Layout.Column(Layout.Inset(card, Tokens.CardPadX, Tokens.CardPadY), Tokens.SpaceXs);
        PanelAtoms.SectionBar(c.Take(Tokens.SectionTitleHeight), "今日概览", "3 项", true);
        PanelAtoms.StatRow(c.Take(22f), "人口", "7", 7f / 12f, Tokens.Accent);
        PanelAtoms.StatRow(c.Take(22f), "食物", "1 240", 0.62f);
        PanelAtoms.StatRow(c.Take(22f), "电力", "-320 W");

        // 图表一行
        var ch = Layout.Row(v.Take(80f), Tokens.SpaceMd);
        Charts.Sparkline(ch.Take(160f), series, Tokens.Accent);
        Charts.LineChart(ch.Take(240f), series);
        Charts.DonutChart(ch.Take(90f), shares, 0.55f, "占比");

        // 输入一行（值由窗口持有）
        var ip = Layout.Row(v.Take(28f), Tokens.SpaceSm);
        if (InputAtoms.Segmented(ip.Take(210f), new[] { "日", "周", "月" }, ref segIndex)) { }
        if (InputAtoms.SliderWithValue(ip.Rest, ref amount, 0f, 1f, 0.01f)) { }

        // 反馈条
        FeedbackAtoms.Toast(v.Take(48f), "已记录", "3 条新档案", ToastLevel.Ok, 1f);

        Layout.EndScroll();

        if (Widgets.ButtonText(col.Rest, "关闭")) Close();
    }
}
