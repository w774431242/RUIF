〇、过滤清单 — 官方引擎完全无法支撑 / 明确不引入

以下内容在 Verse GUI（即时模式、无 DOM、无 WebGL）下无落地路径或与 RUIF 范式冲突，已从目录中剔除，不再评估。
内容评级过滤原因
地理 / 瓦片地图 / 投影图❌ 过滤无地理数据源与投影支持，世界观内无坐标意义。
3D / 旋转 / 透视图表❌ 过滤无 3D 渲染管线，GUI 仅 2D Rect。
WebGL / GPU 加速画布❌ 过滤无 WebGL 上下文，仅 IMGUI。
实时高频流式刷新（>百点/帧）❌ 过滤UI 每帧重绘、无独立渲染线程；大数据必须走脏矩形快照，不承诺流式。
图表导出位图 / PNG❌ 过滤纹理回读链路未验证，依赖 RenderTexture 不在 UI 层承诺范围。
SVG / DOM 输出❌ 过滤无 DOM，SVG 无宿主。
移植 ECharts / D3 / Chart.js❌ 过滤三者依赖 DOM/Canvas 2D API，引擎内不可用；只吸收其视觉范式。
字体级排版渲染（富文本排版引擎）❌ 过滤只有 GameFont 三档字号，无字形级排版能力。
