# 原版 UI 基础原子规模深挖（回答「原版就这么点吗」）

**问题**：演武场的「基础原子层 = 42 件」——原版真就这么点吗？
**方法**：反编译 `Assembly-CSharp.dll` 全量计数 + 逐类方法名抽取（可复现命令见 §7）
**日期**：2026-09-13 ｜ 关联：`原版UI代码标准（Spy取证）.md`、`原子落地基准表.md`

---

## 0. 结论先说

> **不是。42 既不是原版全部，也不是 RUIF 全部。**
> 「42」是**「基础原子层」的策展口径**（L0/L1 地基件），设计目标是**最小完备基**，不是原版镜像。

| 口径 | 规模 | 说明 |
|---|---|---|
| 演武场「基础原子层」 | **42 件** | A0 23（文本/几何/状态/视觉）+ A0+ 19（表格/面板/交互/进度/杂项） |
| **RUIF 实际原子面** | **74 类 / 498 个 `public static`**；其中原子类 ≈36 个、≈236 个方法 | 含 `Input*` / `InputEx*` / `InputPlus*` / `Chart*` / `DataEx*` / `Industrial` / `OfficialData*` / `*Cand*` 等**演武场未收录**的族 |
| **原版 `Verse.Widgets`** | **179 静态成员 / 106 个唯一方法** | 原版自己的「控件绘制 + 交互判定」总面 |
| **原版 UI 全部可调用面** | **≈550 个公开成员** | 见 §2 |

**倍数关系**：RUIF 实际原子面是 42 件的 **≈5.6 倍**；原版 `Widgets` 可调用面是 42 件的 **≈4.3 倍**。

## 5. **真缺口**（原版有、RUIF 全库 0 命中）

检索方式：`Select-String Assemblies\RUIF.xml -Pattern <关键词>`，命中数为 0 且确认非注释。

| # | 缺口 | 原版方法 | 影响 | 严重度 |
|---|---|---|---|---|
| **G1** | **图标族** | `DefIcon` / `ThingIcon`×2 / `GetIconFor`×3 / `CanDrawIconFor` / `InfoCardButton`×8 / `InfoCardButtonCentered`×2 | 原版**最高频** UI 元素（每个物品/建筑/动物都要画图标）；RUIF 只有 `InteractAtoms.ToolbarIcon`（字形按钮，非资产图标） | **高** |

## 6. 为什么会有这些缺口（分析）

| 根因 | 说明 |
|---|---|
| **R1 · 42 是「最小完备基」的设计口径** | 42 件的选择标准是「**L0/L1 地基层 + 每家工坊实证**」，不是「原版镜像」。设计目标是让上层组件有稳定地基，而非穷举原版方法 |
| **R2 · 缺口集中在「资产型」能力**（G1 图标 / G3 阴影 / G4 贴图适配） | 这些依赖 `Texture2D` / `Graphic` / material 系统，属**原版资产层**；RUIF 的设计选择是「让调用方直连原版」，不重复封装 |
| **R3 · 缺口集中在「环境型」能力**（G2 分组裁剪 / G5 跟随标签） | 它们与具体场景（Map / 窗口 / 光标）绑定，不是「可复用原子」；封装收益低 |
| **R4 · 半覆盖是「有意替代」** | `Segmented` 取代 `RadioButton`、`EyeToggle` 取代可见性语义的 `Checkbox` —— 已在文档明示，属设计决策 |
| **R5 · `*Cand*` 族的存在说明缺口是「分层的」** | RUIF 把未定型件放在 `*Cand*`（候选）命名空间（`ChartCandAtoms` / `DataCandAtoms` / `InputCandAtoms` / `NavCandAtoms` / `FeedbackCandAtoms` / `TableCandAtoms` / `DomainCandAtoms` / `LayoutCandAtoms`），说明「已识别但未定稿」 |

## 7. 复现命令

```powershell
$dll='e:\SteamLibrary\steamapps\common\RimWorld\RimWorldWin64_Data\Managed\Assembly-CSharp.dll'
$il="$env:USERPROFILE\.dotnet\tools\ilspycmd.exe"

# 原版单类型（-o 指定输出目录，产物 <Ns>.<Type>.decompiled.cs；0 字节 = 类型不存在）
& $il $dll -t Verse.Widgets -o $env:TEMP\rw_spy
(Get-Content "$env:TEMP\rw_spy\Verse.Widgets.decompiled.cs" |
  Select-String '^\s*public static ').Count          # ⇒ 179

# 唯一方法名（去重）
Get-Content "$env:TEMP\rw_spy\Verse.Widgets.decompiled.cs" |
  ForEach-Object { if ($_ -match 'public static\s+[\w<>\[\]\?\.]+\s+(\w+)\s*\(') { $Matches[1] } } |
  Sort-Object -Unique                                 # ⇒ 106

# RUIF 全量（单次反编译整个 dll，再按类块解析）
& $il Assemblies\RUIF.dll -o $env:TEMP\ruif_all
$t = Get-Content "$env:TEMP\ruif_all\RUIF.decompiled.cs" -Raw -Encoding UTF8
$ms = [regex]::Matches($t, '(?m)^public (?:static |sealed |abstract )*class (\w+)')
# 逐块统计块内 '^\s*public static ' ⇒ 74 类 / 498 个 public static
```
