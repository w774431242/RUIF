评估维度：① RUIF 工程规范符合度；② RimWorld 1.6 官方引擎支持度
评估方式：静态源码实证扫描（非设计草案），时间戳锚定 v1.0.0（RUIF.dll 2026-09-09 20:02）

## 一、RUIF 规范符合度

| 铁律 / 约束 | 实证结果 | 判定 |
|---|---|---|
| 主题令牌单一真源（组件禁 `new Color`） | `new Color` 共 35 处，其中 32 处在 `Theme.cs`（L1 真源，合法）+ `Draw.cs` 2 处（`WithAlpha`/`ColorScope` 合法派生助手）；**组件层仅 3 处且均为有意例外**（见下） | ✅ 通过 |
| 组件层 Color 例外（受控，非 UI chrome） | `InputExAtoms.HsvColor`（注释"避免依赖 Color.HSVToRGB"，取色器）、`VisualAtoms.GradientBar`（`Color.Lerp` 数据渐变插值） | ⚠️ 受控例外，建议文档化 |
| 零分配即时模式（Draw 作用域） | `ColorScope/EnabledScope/FontScope/AnchorScope/RotateScope` 全为 `readonly struct` + `using` 嵌套恢复，避免 GUI 染色泄漏 | ✅ 通过 |
| 布局游标零分配 + 自动裁剪 | `VStack/HStack/Grid` 全 struct，超边界自动 `Mathf.Min` 裁剪，不溢出容器 | ✅ 通过 |
| 分层边界（绘制原子不消费输入） | `Mouse./Event.` 仅落在 `Input*/Interact/Nav/Table` 原子；`Visual/Text/Status/Progress/Panel/Shapes` 不读输入 | ✅ 通过 |
| 官方 API 单一真源 | 仅 `Widgets./GUI./Text./Mouse./Event.`；`GenUI/TexUI/Verse./UnityEngine.*直接类型/GUIClip/反射` 全 0 引用 | ✅ 通过 |
| 测试覆盖 | 17 测试类、110 显式 + 12 参数化 = **122 用例**；覆盖 23 个组件文件中的 **22 个** | ⚠️ 缺口见下 |

## 二、RimWorld 1.6 官方引擎支持度

| 检查项 | 实证结果 | 判定 |
|---|---|---|
| 绘制 API 面 | 仅 `Widgets.DrawBoxSolid` / `DrawLineHorizontal` / `DrawLineVertical` / `Label` / `BeginScrollView` / `EndScrollView` + `GUI.color/matrix/enabled` + `Text.Font/Anchor` | ✅ 稳定公开 IMGUI |
| 数据模型依赖 | `OfficialDataAtoms*` 仅引用 `DefDatabase`/`ThingDef`/`Pawn` 各 1 处（公共 API） | ✅ 无私有访问 |
| 反射 / Harmony | 全工程 0 处 `Traverse/AccessTools/GetField/BindingFlags` | ✅ 纯 vanilla，不硬依赖第三方 |
| 1.6 已知坑处理 | `DrawBoxSolid` 会重置 `GUI.color` → tint 直接传参（`Draw.Box` 注释已固化）；`Draw.Rotate` 用 `GUI.matrix` 作用域正确恢复 | ✅ 已规避 |
| 非官方表面 | 无任何 `RenderTexture/Material/Graphics` 自定义、`GUIClip`、WebGL、地理/3D | ✅ 未越界 |

### 结论
全部落地组件**仅依赖 RimWorld 1.6 长期稳定的即时模式公开 API**，无反射、无 Harmony、无第三方硬依赖——官方支持度为 **完全支持**。
