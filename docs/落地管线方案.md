# RUIF · 落地管线方案（重构版）

> 日期：2026-09-09 · 取代原「I1–I4 按组件数量分批」管线
> 重构原则：**风险驱动**（不确定性最高的先做）+ **垂直切片**（每阶段都产出游戏内可验证物）+ **门禁退出**（防止无限膨胀）
> 关联：`组件设计图鉴.html`（152 组件 / 12 版式 / 12 预设）· `接入指南与引擎可行性审计.html`（✅/⚠️/❌ 分级）

---

## 1. 为什么重构原管线

| 原管线问题 | 表现 |
|---|---|
| 无前置 | 10+ 个官方 API 名挂着「编码期反编译核实」，却已排进编码批次 |
| 无地基 | 连一个可编译、可加载、可开窗的空壳都没有，风险无法收敛 |
| 按数量分批 | I2「26 件组件」以数量为单位，容易只堆数量不验收 |
| 无验证闭环 | 没有单测 / 游戏内 Gallery / Player.log 验证步骤，"改好没"无法判定 |
| 验收错层 | 逐件验收组件，而不是用「能否搭出预设页面」验收 |

**核心改动**：新增 **I0 地基冲刺**，并把后续阶段改为**垂直切片**（每阶段都能在游戏里看到东西）。

## 2. 新管线总览（I0 → I5）

```text
I0 地基冲刺 ──► I1 内核（L0/L4/令牌）──► I2 原子层 ──► I3 组件层（预设驱动验收）
                                                          │
                                                          ▼
                                        I4 交互与扩展 ──► I5 收口与发布 ──► v1.1 素材件
```

| 阶段 | 一句话目标 | 主要交付 | 关键验收 |
|---|---|---|---|
| **I0 地基冲刺** | 消灭"未知"与"不可验证" | API 签名核实清单 · RUIF.csproj · 空窗口 + 示例消费 Mod · 单测/同步脚本 | 编译 0 错 0 警 + 游戏内开窗成功 |
| **I1 内核** | 只做承重墙，不做组件 | `Draw.Scope` · Layout（VStack/HStack/Grid/ScrollView/Split）· Theme 核心（Vanilla/Dark）· 布局原子 | 布局单测 + 绘制态泄漏检查 |
| **I2 原子层** | 让上层代码塌缩引用 | A0 原子 42 件全量 | Gallery 原子页逐件可交互 |
| **I3 组件层** | 用页面验收组件 | B 输入 28 + C 数据纯 ✅ 件 | **用 G 预设至少 2 个页面成功复刻** |
| **I4 交互与扩展** | 主题注册 + 焦点仲裁 | D 反馈 17 + E 导航 12 + 第三方注册 + Gallery 完整版 | 多主题实机切换 + 键盘导航 + 焦点冲突回归 |

| **v1.1（后置）** | 素材与算法件 | Charts 折线 · RelationGraph · ProgressRing 弧形 · MiniMap · 世界空间气泡 | 原型先验证，通过才进主线 |

## 3. 各阶段详述

### I0 · 地基冲刺（最高优先级，其他阶段的前置）

**① API 签名核实清单**（ilspycmd 反编译，输出表：名称 / 签名 / 所在程序集 / 是否可用 / 替代方案）
待核实项（当前挂"编码期核实"的）：
`WealthWatcher` · `HistoryEvent` · `BillStack` · `Tale` · `PawnRecords` · `Psycast` · `Caravan` · `KeyPrefs` · `Widgets.TextFieldNumeric` · `Widgets.DrawTextureRotated` · `GenDate`（补签名）· `GenText` · `GenColor`
> 已核实（知识库）：`GenDate`/`GenText`/`GenColor`（Gen 工具族）、`FloatMenu`/`FloatMenuOption`（§38 核心 UI 族）、`QuestScriptDef`/`QuestNode`（§140）、`RoyalTitle`/`Permit`（§233）、`Ideo`/`Precept`（§237）、`GeneDef`（Def 分册）

**② 工程骨架**
- `RUIF.csproj`：`net48 / x64`，引用 `Assembly-CSharp` / `Verse` / `UnityEngine`；**核心不引 Harmony**
- 空 `Window` 子类 + 示例消费 Mod 工程（验证"引用 dll 但不内嵌"的接入模式）

**③ 验证闭环**
- 单测工程（布局/令牌/截断/解析器）
- 游戏内占位 Gallery 窗口
- Player.log 验证步骤（每个阶段都要有日志留证）
- 两区同步 + 哈希校验脚本（发布区路径 TBD，脚本先行）

**退出条件**：所有"待核实" API 均有结论（可用 / 不存在 / 替代方案）。

---

### I1 · 内核（L0 + L4 + 令牌）

| 交付 | 说明 |
|---|---|
| `Draw.Scope` | `GUI.color` / `GUI.enabled` 栈式配对，退出必恢复；内建 1.6 约束（DrawBoxSolid 重置 color、ButtonText 无 disabled 用 active、RadioButton 无 Group、TipSignal 第二参=秒） |
| Layout | `VStack` / `HStack` / `Grid(cols)` / `ScrollView` / `Split(ratio)` / `Spacer` + Dirty 复用规则 |
| Theme 核心 | Vanilla（默认）/ Dark 两套令牌，`Register(id, palette)` / `Apply(id)`，未注册回退默认 |
| 布局原子 | `AspectBox` / `AnchorFrame` / `Spacer` / `SectionFrame` |

**门禁**：0 错 0 警 · 布局单测（嵌套/溢出/滚动作废）· grep 无裸 `GUI.color` · Gallery 布局示例实机。
**明确不做**：任何业务组件。

---

### I2 · 原子层（A0 42 件）

四族全量：文本原语 6 · 几何装饰 6 · 状态原子 5 · 布局视觉 6 · 表格原子 5（Numbers/Work Tab）· 面板原子 4（RimHUD）· 交互原子 4 · 进度容量 3 · 杂项 3 · 官方原子 6。

**为什么组件之前先做原子**：原子就位后，I3 的 68 个组件里大量重复逻辑（单位排版、时间格式、状态点、展开箭头、截断）直接塌缩为原子引用，总体工作量下降且一致性更高。

**门禁**：Gallery 原子页逐件可交互 · CJK 截断与 22f 行高**实机校准** · 单测覆盖 `FormattedNumber` / `TimeStamp` / `TruncateToWidth`。

---

### I3 · 组件层（预设驱动验收）

- 交付：B 输入 28 件（含 `PaintStroke` / `PriorityGrid` / `TimetableMatrix` 等工坊实证件）+ C 数据中**纯 ✅** 部分（图表/关系图/MiniMap 留 v1.1）
- **验收方式改变**：不再逐件打勾，而是**用 G 预设页面验收**——至少成功复刻 ①总督仪表盘 ②殖民者档案 两个页面（组件搭不起页面 = 组件不合格）
- 门禁：页面实机截图 + Player.log 无异常 + 单测通过 + 绘制态检查

---

### I4 · 交互与扩展

- 交付：D 反馈 17 + E 导航 12 + 第三方主题/组件注册 + `CommandPalette` / `HotkeyBind` 焦点仲裁 + Gallery 完整版
- 门禁：多主题实机切换 · 键盘 Tab 导航可达全部交互件 · **焦点冲突回归**（与游戏快捷键抢占）· Toast/NotificationTray 队列实测

---

### I5 · 收口与发布

- 交付：API 冻结 + SemVer + `[Obsolete]` 过渡策略 · Workshop / GitHub 发布 · 语言子包（借鉴 RimHUD）· 示例消费 Mod · 降级路径
- 门禁：示例 Mod 接入成功 · **禁用 RUIF 后降级路径实测可用** · 两区同步哈希一致 · 文档与图鉴一致

### v1.1（后置，不进 v1.0 承诺）

Charts 折线逼近 · RelationGraph · ProgressRing 弧形（贴图/折线）· MiniMap（RenderTexture 原型）· 世界空间气泡/飘字 —— **每件先做原型，通过才进主线**。

## 4. 并行策略与关键路径

| 可并行 | 说明 |
|---|---|
| API 核实 ‖ 工程骨架 | I0 内两件事互不依赖 |
| 文档 ‖ 编码 | 图鉴/接入指南随实现同步更新 |
| 单测 ‖ 实现 | 布局与令牌层先测后写（TDD 友好） |
| Toast/Alert 提前 | D 中简单件不必等 I4，可在 I3 尾插入 |

**关键路径**：`I0 → I1 → I2 → I3`（主线不可跳过）；I4 部分可前移；I5 依赖前三。

## 5. 风险登记册

## 6. 全局门禁（每阶段都必须过）

```text
[ ] 编译 0 错 0 警（C:\dotnet8\dotnet.exe build ... -c Release）
[ ] 单测通过（布局 / 令牌 / 截断 / 解析器）
[ ] 游戏内 Gallery 逐件可交互（实机，非截图设想）
[ ] grep 红线：无裸 GUI.color / new Color
[ ] Player.log 无异常（对应阶段留证）
[ ] 文档与图鉴同步更新
[ ] I5 追加：示例 Mod 接入 + 降级实测 + 两区同步哈希一致
```
