## §5 审计协议（A 单元 10 条 · 恢复版）

> 原始 10 条随文件丢失，本版按自动化协议「硬规矩」与 MEMORY 工程红线重建，语义等价：

1. **构建 0 错 0 警**（含 CS0649 死状态、CS0169 未用字段）。
2. **规格同源**：几何/配色/文案与宝典 HTML 对应 `.demo` 块一致；RUIF 原子契约以反编译实测为准，不凭签名猜。
3. **尺寸取自 `Measure.*`**，`BodyH` 算足（Tiny 18 / Small 22），不留白不截断。
4. **标签用单元矩形 + 二次分行**；`VStack/HStack` 游标不得取 `.x/.y/.width/.height`（只能 `Take()/Rest`）。
5. **交互件 ≥I2**：命中检测 + 状态归调用方 + `HoverFrame` 悬停（禁用态不得挂 HoverFrame）。
6. **逐件 `try/catch`**，异常不逃逸出 Render。
7. **新增件有 `MinW/MinH` + 空间守卫**（小窗不重叠不越界）。
8. **无假演示/编造数据**：需运行时数据的件显示「— + 原因」。
9. **状态字段随件声明、真实可达**（不可达即删或赋语义，避免 CS0649）。
10. **反查编号**：`Api` 行首 `[XX-nn]` 与 `StdIds.gen.cs` 一致（构建后目视抽验即可）。
