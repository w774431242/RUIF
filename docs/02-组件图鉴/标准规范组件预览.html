标准规范组件 · 概览

Source/Components/*CandFmt.cs · *CandAtoms.cs

v1.4.0 起，RUIF 将分散的原子组件统一为「候选层」：每个组件家族提供 *CandFmt（参数对象，纯构建、零副作用）与 *CandAtoms（单入口绘制 Xxx(Rect, cand)）。调用方不再直接拼装坐标与颜色，而是传入标准化参数，由框架保证行高、间距、语义色与降级全部合规。

问题 → 方案： 早期组件仅暴露底层 API（如 Draw.Label(rect, …)），调用方必须手填字号/颜色/矩形，导致「差评过高、不可直接调用」。候选层把「尺寸来自 Measure、颜色来自 Tokens」内聚进 Fmt 与 Atoms，调用方只需 PanelCandFmt.StatRow(…) → PanelCandAtoms.StatRow(rect, cand)。原 *Atoms 实现被完整复用，向后兼容。
调用范式（三步）约定
① Fmt 构建：var cand = PanelCandFmt.StatRow("采矿", "12", 0.6f);
② 尺寸 + Atoms 绘制：Rect row = new Rect(parent.x, parent.y, 240f, Measure.RowHeight(Tokens.FontBody)); PanelCandAtoms.StatRow(row, cand);
③ 复用原实现：*CandAtoms 内部转发至原 PanelAtoms.StatRow，行高/语义色由框架统一裁决。

参数对象为 readonly struct，不可变；绘制入口固定签名 (Rect, Cand)，便于列表/重排批量调用。

设计契约（强制内聚）Tokens·Measure
· 字号：Tokens.FontLabel=Tiny / FontBody=Small / FontValue=Medium
· 行高：Measure.RowHeight(font)（转发引擎，不得缓存）
· 控制高：Measure.ControlHeight = RowHeight + 8
· 语义色：全部来自 Tokens.*，禁止硬编码色值

下方「设计令牌」一节列出全部真值，预览渲染严格对齐，不臆造。

推荐尺寸（可直接复制成型）尺寸参数
· 所有组件卡的「复制」按钮均输出含 Rect 的完整 C# 成型代码。
· 宽度为组件族常规推荐值（如 240f / 200f），可按 parent.width 调整。
· 高度优先使用 Measure.RowHeight(Tokens.Font*) 或 Measure.ControlHeight。
· 垂直间距使用 Tokens.SpaceXs / SpaceSm / SpaceMd，保持整页节奏一致。

推荐尺寸不是强制约束，而是基于框架真值的「开箱即用」默认值；调用方仍可用任意 Rect 覆盖。
