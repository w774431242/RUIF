一、第一批 · T1 四原子（≈3 人日，含反馈类 Gallery 接线）

工业管理方向最缺的表达层原子。全部纯绘制件（读参不读世界），沿 Fmt+Atoms 双件范式。
Gauge 指针表盘≈0.5 人日
半环分区（死/警/活）+ 指针 + 数值。数据源 CompPowerTrader 功率比。官方实证：PowerNet(31)
LEDMatrix 状态灯阵≈0.5 人日
设备群一览灯阵，一格一机，颜色即状态。数据源 CompBreakdownable。官方实证：BreakdownManager
BottleneckRibbon 瓶颈带≈1 人日
流程各环节耗时占比条带，最宽等待段标红即瓶颈。数据源 Bill_Production 队列耗时。官方实证：BillStack
MachineStateTimeline 设备状态时序≈1 人日
多机 × 时段状态带（运行/怠速/故障/加油）。数据源 HistoryUtility 序列。官方实证：HistoryUtility

二、第二批 · DataBridge v1 域面板（≈5 人日，Power+Stock 两域）

组件本体复用 v1.1 Charts（Line/Bar），新增的是数据桥与两个域——面板只是第一批受益者。
PowerDomain 能源监测板≈2.5 人日
发电 vs 负载双序列，采样点即真值。数据源 CompPowerTrader.PowerOutput。官方实证：CompPowerTrader
StockDomain 库存水位板≈2.5 人日
资源水位 + 最低安全线告警。数据源 ResourceCounter.Count。官方实证：ResourceCounter(21)

三、第三批 · 孪生复合件（≈6 人日，MapDomain）

数字孪生核心三件：把地图世界压成俯视抽象图。依赖 DataBridge 的 MapDomain 快照。
GridMap 俯视状态格网≈2.5 人日
Map cell 采样 → 温度/电力/占地热力俯视，Zone 叠加描边。数据源 Map/Zone。官方实证：ZoneManager
CircuitTopology 电路拓扑≈2 人日
发电 → 储能 → 负载连线图，负载标占用率。数据源 PowerNet.powerComps。官方实证：PowerNet
ProductionFlow 生产链看板≈1.5 人日
账单队列 → 工作台 → 产出 流向图。数据源 BillStack / Building_WorkTable。官方实证：Bill_Production
